# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Report them privately through GitHub: [Report a vulnerability](https://github.com/dev-rb-hub/symbio-hub/security/advisories/new).

Include the affected component, steps to reproduce and the impact you observed. Do not include real personal or payment data.

## Scope and status

Symbio Hub is pre-release. Security posture, including which controls are implemented and which are planned, is described in [docs/compliance/README.md](docs/compliance/README.md). Nothing in this repository is a statement of certification or regulatory compliance.
