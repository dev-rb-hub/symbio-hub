# Frontend Agent Instructions

This file helps AI agents working in the frontend/Symbio.Frontend workspace.

## Focus
- Keep frontend changes inside `frontend/Symbio.Frontend` unless a cross-cutting change is required.
- Preserve the existing React 18 + TypeScript + Vite structure and route layout in `src/pages`, `src/components`, `src/components/routing`, and `src/context`.
- Prefer small UI changes that fit the current styling and component structure.

## UI constraints
- Use React Router for navigation and preserve the existing public/protected route split.
- Keep role-aware UI behavior consistent with the current auth context and route guards.
- The Expert workbench consumes the backend SignalR endpoint at `/hubs/workbench`; keep live updates compatible with that contract.
- Avoid adding frontend dependencies unless the change clearly needs them.

## Common tasks
- Validate changes with `npm run lint` and `npm run build`.
- Run the local dev server with `npm run dev`.
- When using the containerized stack, the frontend is served on `http://localhost:5173` and proxied to the backend service.

## Agent guidance
- Preserve the existing component and page structure.
- Prefer the current auth context, route guards, and page modules over introducing new app-wide abstractions.
- Keep UI text, routing, and state changes consistent with the current user roles and route map.
- Link to the root repository guidance in `AGENTS.md` for broader repo conventions.
