# Frontend Agent Instructions

This file helps AI agents working in the `frontend/Symbio.Frontend` workspace.

## Focus
- Keep frontend changes inside `frontend/Symbio.Frontend` unless a cross-cutting change is required.
- Do not expose backend database schemas or internal API implementation details in frontend code.
- Prefer UI, routing, and component improvements that respect the existing React 18 + Vite + TypeScript architecture.
- Keep changes aligned with the current page/component layout in `src/pages`, `src/components`, `src/components/routing`, and `src/context`.

## UI constraints
- Use React Router for navigation and preserve the existing public/protected route split.
- Keep role-aware UI behavior consistent with the current auth context and route guards.
- Keep Expert workbench live updates compatible with the backend SignalR endpoint at `/hubs/workbench`.
- Favor small, local UI changes that fit the existing simple, lightweight styling approach unless the task explicitly calls for a redesign.
- Avoid adding frontend dependencies unless they clearly improve the feature or fix the bug.

## Common tasks
- Use `npm run lint` to validate TypeScript and ESLint rules.
- Use `npm run dev` to run the Vite development server locally.
- Use `npm run build` for production build validation.
- Use `npm run preview` only when you need to inspect the production build locally.

## Agent guidance
- Preserve the existing component and page structure.
- Prefer the existing auth context, route guards, and page modules over introducing new app-wide abstractions.
- Keep UI text, routing, and state changes consistent with the current user roles and route map.
- Link to root repository guidelines in `AGENTS.md` when broader repo conventions matter.
