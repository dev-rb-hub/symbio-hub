# Backend Agent Instructions

This file helps AI agents working in the backend workspace.

## Focus
- Keep backend work inside `backend/` and avoid introducing frontend dependencies.
- Preserve the existing .NET architecture: API, Core, and Infrastructure.
- The API host lives in `backend/Symbio.API`, domain contracts live in `backend/Symbio.Core`, and integrations or repositories live in `backend/Symbio.Infrastructure`.
- Prefer existing controllers, services, and repository patterns over introducing new abstractions.

## Common tasks
- Validate changes with `dotnet test`.
- Run the API locally with `dotnet run --project backend/Symbio.API`.
- Expect Swagger and a `/health` endpoint when the API starts successfully.
- The expert workbench live channel is exposed at `/hubs/workbench` and requires an authenticated `Expert` role token.

## Agent guidance
- Keep implementation changes small and aligned with the current .NET structure.
- When touching payments, onboarding, or billing flows, follow the existing service and repository boundaries rather than bypassing them.
- Do not leak database schema, internal implementation details, or secrets into frontend code or documentation.
- Use the root guidance in `AGENTS.md` for broader repository conventions.
